# 遊戲內驗收清單

自動化測試是邏輯與模擬環境測試，無法涵蓋觸控、視覺與伺服器行為。以下項目需要在實際 BC 伺服器驗證（私訊與分享類需兩個帳號）。完成後請直接從此清單刪除。

## 通訊
- [ ] 兩帳號互傳 BEEP／悄悄話；悄悄話的 Hidden 附件封包、原生回覆 ID 與 FCM 回覆 ID 的降級行為
- [ ] `@ID` 私密 Profile 分享：小檔單封包、大檔 800 字元分塊重組；收到後只保存較新的資料
- [ ] 對方離線時文字排隊、回來後送出；Profile 提及不排隊且保留輸入框文字
- [ ] 與 LCE、獨立 Liko-WPS 同房時的 PROFILESHARE 接收優先序（FCM > LCE > WPS）
- [ ] 啟用 BCX 規則時：預設遵守限制；開啟繞過選項後收發正常

## 面板與房間
- [ ] 玩家排序：房管在真實房間拖曳／點選的交換與插入，觸控裝置操作，3 秒未確認回復
- [ ] 圖示、氣球拖曳／吸附與頁面縮放在手機模式的表現
- [ ] 關係圖在大型 Profile 資料庫（超過警告門檻）下的效能與停止／繼續

## 相容
- [ ] 與 AFC 同載入時，戀人面板展開的 Profile 頁：底線疊加與點擊優先序
- [ ] 與 LianChat 使用者互動：URL 頭像與簽名可見，FCM 擴充欄位被忽略而不報錯
- [ ] 以目前 BC 版本重新執行 `check:bc -- --bc-dir <BC 原始碼>`；基準為 R133，有差異需人工判斷掛鉤是否仍成立（「已改變」不等於失效，「不再存在」會使掛鉤安裝失敗）

## CHAT 置頂（右鍵選單）

- 左側人員右鍵／手機長按：`聊天` / `置頂（取消置頂）` / `取消` 是否正常，選單位置不超出面板。
- 置頂者排最前；分隔線 0.5pt 主題色，單欄與合併多欄（置頂 3 人 4 欄＝`123`／`4567`）都正確；全部置頂時不畫線。
- FCM 星號與 CHAT 置頂為同一份名單，互相切換後兩邊都同步。

## CHAT 人員右鍵：加入群組／前往房間

- 右鍵「加入群組」展開群組清單，點選加入／再點一次移除（✓ 表示已在群組），「＋ 新群組」建立後直接加入。
- 「前往房間」：好友在公開房且房名已知時可直接點；房名未知時按鈕顯示「取得房名中…」並反灰，背景向伺服器要線上好友資料，取得後自動可點（最多等約 5 秒）；非好友、私人房或同房間者不可用或隱藏。
- 點「前往房間」會開啟既有的加入確認框，並補齊房間詳細資料。

## CHAT 訊息右鍵：匯出／刪除

- 訊息右鍵：`匯出信息`（選取後下方可轉發／匯出 JSON、HTML）與 `刪除信息`（選取後下方顯示已選數量、說明「刪除只對自己有效，對方仍可以看到被刪除信息」、刪除與取消）。
- 刪除前會再確認；刪除後對話、左側清單、未讀氣球同步更新；尚在離線佇列、未送出的訊息被刪除時，佇列也一併移除。
- 刪除只影響本機 IndexedDB 的紀錄，不會通知對方。

## CHAT 未送出草稿

- 在 A 的輸入框打字後切到 B 再切回，草稿仍在；重新整理頁面後仍在（依帳號存於 localStorage）。
- 送出成功後草稿清除；刪除整段對話時草稿一併清除。
